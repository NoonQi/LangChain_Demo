<h1>An application showcasing how langchain works</h1>
<p>A small demo that showcases how using GROQ and GEMINI API keys we can ask questions to a document,that provides the context to the LLM to answer from.</p>
<p>We have further fine tuned it using RAG, and setting the temp low so it doesnt not hallucinate or give random answers.</p>
<h3>Make sure to dd your API keys in .env folder before running it.</h3>
